# AIGO

A full-stack application with **Next.js** frontend and **Express.js** backend.

## Project Structure

```
AIGO-/
├── frontend/   # Next.js 14 (React 18)
├── backend/    # Express.js 4
└── README.md
```

## Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

Server runs on `http://localhost:5000`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

App runs on `http://localhost:3000`.
